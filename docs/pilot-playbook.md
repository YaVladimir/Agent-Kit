# План пилота

Первый пилот запускаем на одном репозитории и одной команде.

## Неделя 1

- Добавить шаблоны репозитория.
- Настроить LSP.
- Добавить `.context/index.md` и `.context/architecture.md`.
- Проверить 3 исторические задачи с контекстом и без него.

## Неделя 2

- Добавить глоссарий, один файл процесса и один файл правила.
- Запустить локальный `gigacode-context` MCP.
- Научить агента вызывать `find_change_points(task)`.

## Неделя 3

- Взять 3-5 реальных задач из бэклога команды.
- Измерить ошибочные точки изменения, замечания на ревью, время до плана и
  наличие тестов.

## Критерии успеха

- Агент находит правильные точки изменения без ручной навигации разработчика.
- Агент переиспользует существующие сервисы и тесты.
- Замечаний на ревью про неправильное место изменения становится меньше.
- Разработчики доверяют плану настолько, чтобы давать агенту небольшие правки.
