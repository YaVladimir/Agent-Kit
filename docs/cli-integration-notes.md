# Заметки по интеграции CLI

Не предполагаем, что внутренний GigaCode CLI доступен локально во время
разработки этого kit.

## Стабильные допущения

- Агент может получить системный промпт или аналогичный слой инструкций.
- Агент может читать файлы репозитория.
- MCP-подобные инструменты можно отдать как настоящие MCP-серверы или как
  корпоративные CLI-инструменты с похожими контрактами.
- LSP-навигация может быть подключена самим CLI, MCP-сервером или обёрткой.

## Граница адаптера

Эти части должны оставаться CLI-независимыми:

- `prompts/*.md`
- `skills/gigacode-java-enterprise`
- структура `.context`
- YAML-схемы
- контракты инструментов в `references/tool-contracts.md`

Эти части адаптируются после знакомства с внутренним CLI:

- путь и схема конфига;
- регистрация MCP-сервера;
- переменные окружения для адреса модели;
- флаги запуска LSP;
- политика разрешённых и запрещённых инструментов.
